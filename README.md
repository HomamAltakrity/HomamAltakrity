# 💫 About Me:
I’m a Frontend Developer with 4+ years of experience, specializing in building scalable, intuitive, and high-performance web and mobile applications. My core expertise lies in Next.js, React, React Native, and modern frontend ecosystems, where I focus on delivering clean architectures, elegant UI/UX, and efficient, production-ready interfaces.

Along with my strong frontend background, I also work as an AI Engineer, developing intelligent solutions that integrate machine learning, automation, and data-driven features into real-world applications. I have hands-on experience with Python, PostgreSQL, Odoo, and cloud technologies, enabling me to build complete end-to-end systems when needed.

I’m currently involved in several projects across web development, automation, and system integrations. At the same time, I’m expanding into VR and game development, using Unity, C#, and 3D environments to create immersive and innovative experiences that combine AI with interactive design.

I’m always excited to collaborate on impactful projects, explore cutting-edge technologies, and build digital products that make a real difference.
